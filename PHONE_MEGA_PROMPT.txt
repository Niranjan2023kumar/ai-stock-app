SECTION 3: THE FIVE LAWS — NEVER BREAK
════════════════════════════════════════════════════════

LAW 1 — ZERO CRASHES (absolute priority #1):
  Every network call, DataStore read, .first(), JSON parse, and anything
  that can throw MUST be inside runCatching{}.getOrElse{ safeDefault }.
  No !! force-unwrap anywhere in production paths. Zero uncaught exceptions.
  Pattern: runCatching { dataStore.data.first() }.getOrElse { defaultValue }

LAW 2 — REAL DATA ONLY (absolute priority #2):
  Yahoo Finance v8 ONLY: https://query2.finance.yahoo.com/v8/finance/chart/SYMBOL?interval=1d&range=1d
  Yahoo Finance v7 is DEAD (HTTP 401) — delete any v7 URL found.
  Angel One SmartAPI: user enters credentials at runtime. Never hardcoded.
  AMFI mfapi.in: free mutual fund NAV — https://api.mfapi.in/mf/{schemeCode}/latest
  ZERO dummy prices. ZERO placeholders. ZERO fake/invented data ever shown to users.

LAW 3 — ZERO JARGON (every user-facing string):
  Test: can a 12-year-old shopkeeper understand it?
  FORBIDDEN → REPLACEMENT:
    stop-loss / stop loss    → safety stop
    book profit              → take your profit
    P&L                      → profit or loss
    SIP (badge/standalone)   → monthly investment
    NAV                      → price per unit
    CAGR                     → yearly growth
    RSI / MACD / ATR         → describe plainly or remove from user view
    HOLD (verdict badge)     → Watching
    PASSED (verdict badge)   → Too late
    breakout                 → price jump
    square-off               → close the trade (or "broker closes it")
    candlestick              → price chart bar
    T1/T2/T3 (bare labels)   → Target 1 / Target 2 / Target 3
    bearish / bullish        → falling / rising
    volatility (user-facing) → the market is jumpy
    ETF (user-facing card)   → ready-made basket of top companies
    NOTE: code field names (stopLoss, bullishCase) can stay technical —
    ONLY Text(), TTS speakText(), notification title/body must be plain.

LAW 4 — APP NEVER TRADES:
  The app ONLY advises. Real buying/selling happens in Groww.
  Never place orders. Never touch user money. Just open Groww for the user.

LAW 5 — FAST AND FREE APIs ONLY:
  Free and fast: Yahoo Finance v8 (no key), AMFI mfapi.in (no key),
                 NSE public APIs (no key), Angel One SmartAPI (user's key).
  Never add a paid API. Never block on a slow API. Always async + timeout.
  If an API is slow (>3s): show cached data + "Refreshing…" spinner.
  If an API fails: hide that section + log the error — never crash or show error to user.
